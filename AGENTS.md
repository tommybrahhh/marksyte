# Marksyte project instructions

## Writing requirements

- Do not end titles, headings or standalone phrases with a period by default.
- This applies to all content added to this project, in both English and Spanish, including:
  - `h1`–`h6` headings, page `<title>` tags and card/case/article titles
  - standalone lines and phrases: eyebrows, kickers, notes, callouts, link labels and short labels
- Periods remain allowed only where grammatically required: full-sentence paragraphs, multi-sentence prose and abbreviations.
- Preserve question marks and exclamation marks where the phrase is a question or exclamation.
- Preserve intentional ellipses (`...`).

### Examples

| Avoid | Use |
| --- | --- |
| Análisis útil para decisiones operativas complejas. | Análisis útil para decisiones operativas complejas |
| Distribution is not scale. It is a data-backed scale test. | Distribution is not scale. It is a data-backed scale test |
| Five rules for border duty free growth. | Five rules for border duty free growth |

Keep the internal period when a heading legitimately contains two sentences; only the trailing period is removed.
